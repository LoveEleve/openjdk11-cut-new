## 二、完整清单（15个对象）

### 第一类：管理类（3个）

| # | 类名 | 类型 | 作用 | 单例？ |
|---|------|------|------|--------|
| 1 | **PerfDataManager** | `AllStatic` | 工厂类，负责创建所有 PerfData 对象 | 是（全静态） |
| 2 | **PerfMemory** | `AllStatic` | 管理共享内存区域（创建/分配/销毁） | 是（全静态） |
| 3 | **PerfDataList** | `CHeapObj` | 列表容器，存储 PerfData 对象指针 | 否（3个实例） |

**PerfDataManager 的3个列表实例**：
```cpp
static PerfDataList* _all;       // 所有 PerfData 对象
static PerfDataList* _sampled;   // 需要采样的对象
static PerfDataList* _constants; // 常量类型对象
```

---

### 第二类：C++ 数据对象（8个）- 运行时

#### 继承层次

```
CHeapObj<mtInternal>
    └── PerfData (抽象基类，4个字段)
            ├── PerfLong (数值型)
            │       ├── PerfLongConstant (常量)
            │       └── PerfLongVariant (可变)
            │               ├── PerfLongVariable (变量)
            │               └── PerfLongCounter (计数器)
            │
            └── PerfByteArray (字节数组)
                    └── PerfString (字符串)
                            ├── PerfStringConstant (字符串常量)
                            └── PerfStringVariable (字符串变量)
```

| # | 类名 | 父类 | 作用 | 典型用途 |
|---|------|------|------|----------|
| 4 | **PerfData** | `CHeapObj` | 抽象基类，定义通用接口和字段 | 不直接实例化 |
| 5 | **PerfLong** | `PerfData` | 长整型数据基类 | 不直接实例化 |
| 6 | **PerfLongConstant** | `PerfLong` | 常量长整型（创建后不变） | JVM 版本号、启动时间 |
| 7 | **PerfLongVariant** | `PerfLong` | 可变长整型基类 | 不直接实例化 |
| 8 | **PerfLongVariable** | `PerfLongVariant` | 变量（可任意修改） | 当前堆大小 |
| 9 | **PerfLongCounter** | `PerfLongVariant` | 计数器（单调变化） | GC 次数、编译次数 |
| 10 | **PerfByteArray** | `PerfData` | 字节数组基类 | 不直接实例化 |
| 11 | **PerfString** | `PerfByteArray` | 字符串基类 | 不直接实例化 |
| 12 | **PerfStringConstant** | `PerfString` | 字符串常量 | 命令行参数、JVM 版本 |
| 13 | **PerfStringVariable** | `PerfString` | 字符串变量 | 当前 GC 原因 |

---

### 第三类：共享内存结构（2个）- 外部可见

存储在 `/tmp/hsperfdata_<user>/<pid>` 文件中：

| # | 结构名 | 类型 | 作用 | 大小 |
|---|--------|------|------|------|
| 14 | **PerfDataPrologue** | `struct` | 共享内存文件头部（魔数、版本等） | ~40 bytes |
| 15 | **PerfDataEntry** | `struct` | 每个计数器的条目头部（元数据） | 32 bytes |

---

### 第四类：辅助类（2个，可选）

| 类名 | 作用 |
|------|------|
| **PerfLongSampleHelper** | 采样辅助类，用于定期采样数据 |
| **PerfTraceTime** / **PerfTraceTimedEvent** | 计时工具类，用于测量代码块执行时间 |

## 四、各对象内存占用

### C++ 对象（x86_64）

| 类 | sizeof | 说明 |
|----|--------|------|
| PerfData | ~48 bytes | 基类，虚表指针 + 6个字段 |
| PerfLong | ~48 bytes | 继承自 PerfData，无新增 |
| PerfByteArray | ~56 bytes | + _length (jint + padding) |
| PerfString | ~56 bytes | 继承自 PerfByteArray |
| PerfStringVariable | ~56 bytes | 继承自 PerfString，无新增 |
| PerfLongConstant | ~48 bytes | 继承自 PerfLong，无新增 |
| PerfLongVariable | ~64 bytes | + _sampled + _sample_helper |
| PerfLongCounter | ~64 bytes | 同 PerfLongVariable |

### 共享内存结构

| 结构 | sizeof | 说明 |
|------|--------|------|
| PerfDataPrologue | 40 bytes | 文件头部 |
| PerfDataEntry | 32 bytes | 条目头部 |
| 实际数据 | 可变 | 名称字符串 + 数据值 + padding |

## 五、总结

### 回答你的问题：到底涉及几个对象？

| 场景 | 涉及对象数 | 说明 |
|------|-----------|------|
**创建1个字符串计数器** | 3个 | 1个 C++ 对象 + 1个共享内存条目 + 1个列表注册 |
| 完整系统 | 15个类/结构 | 3管理 + 8数据 + 2共享内存结构 + 2辅助 |

### 关键区分

| 存储位置 | 生命周期 | 谁能访问 |
|----------|----------|----------|
| **C++ 对象** | C Heap | JVM 进程内（内部管理用） |
| **共享内存条目** | 文件 `/tmp/hsperfdata_*` | 任何进程（外部工具用） |

**一句话**：
> C++ 对象是"管理员"，共享内存条目是"公开档案"。管理员持有档案的指针，外部工具直接读档案。
