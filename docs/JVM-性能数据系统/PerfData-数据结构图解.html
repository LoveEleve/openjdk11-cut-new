图 4: create_string_variable 执行流程
1
参数处理
检查 max_length，如果为0则使用 strlen(s) 自动计算
↓
2
5层构造函数链（核心）
new PerfStringVariable()
└─▶ CHeapObj() → PerfData() → PerfVariable() → PerfString() → PerfStringVariable()
↓
3
共享内存分配
在 PerfMemory 中分配 max_length+1 字节，存储字符串数据
↓
4
有效性检查
成功: is_valid() 返回 true → 继续
失败: is_valid() 返回 false → delete + 抛出 OOM
↓
5
注册到全局列表
add_item(p, false) 将对象添加到 PerfDataManager 的内部列表
↓
6
返回对象指针
返回 PerfStringVariable*，可被外部访问和修改

🎯 一图胜千言总结

5层继承

CHeapObj → PerfData → PerfVariable → PerfString → PerfStringVariable

2块内存

C++ 对象在堆上，字符串数据在共享内存（mmap）

1个目的

让外部工具（jstat/jps/jconsole）能读取 JVM 性能数据
