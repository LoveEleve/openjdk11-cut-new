JVM 启动流程 - Agent 与全局数据初始化

Phase 3 深度解析 | thread.cpp:3980-4065 | OpenJDK 11

🎯 核心原理

本质是什么？

Phase 3 是 Agent 加载与全局基础设施准备阶段，完成两件事：加载 JVMTI Agent + 初始化 VM 级全局数据结构。

为什么需要？

Agent 需要在 Java 代码执行前开始工作；全局状态（线程列表、锁、内存池）必须在创建第一个 JavaThread 前准备好。

怎么解决？

1. Agent 状态机：OnLoad → Primordial 阶段转换
2. AgentLibrary 链表管理多个 Agent
3. vm_init_globals() 一站式初始化

为什么这样设计？

Agent 的 Agent_OnLoad 可能需要访问全局数据；集中初始化确保依赖顺序正确。

🎯 Phase 3 核心要点

  • Agent 是外部扩展：JVMTI 让外部工具能在 JVM 启动早期介入（调试器、Profiler）
  • 状态机管理：OnLoad → Primordial 阶段转换是 JVMTI 规范要求
  • 主线程是原型：第一个 JavaThread 的创建流程是后续线程创建的模板
  • 基础设施先行：Mutex、ChunkPool 等必须在任何 Java 代码执行前就绪
