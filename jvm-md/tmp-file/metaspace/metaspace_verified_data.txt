=========================================================
= 4. 关键验证结论
=========================================================

1. Boot ClassLoader 首个数据 Chunk = 4MB (Humongous级别) ✅
2. Boot ClassLoader 首个类 Chunk = 384KB (Humongous级别) ✅
3. 数据 VSL 预留 8MB = 2×4MB (VIRTUALSPACEMULTIPLIER=2) ✅
4. 类 VSL 预留 1GB = CompressedClassSpaceSize ✅
5. 压缩类指针: base=0x800000000, shift=0 ✅
6. ChunkManager 初始为空 (所有chunk都在SpaceManager中使用) ✅
7. MetaspaceGC 阈值: 初始化时=MAX_SIZE, post_init后=20.80MB ✅
8. java -version 启动只用了约 5.61MB 元空间 (5.04MB数据 + 586KB类)
9. Anonymous/Reflection ClassLoader 使用 Specialized chunk (128 words = 1KB) ✅
   (post_initialize后的 take_from_committed 显示大量 chunk_word_size=128 的分配)
