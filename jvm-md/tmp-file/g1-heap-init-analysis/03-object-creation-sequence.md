# G1堆初始化对象创建时序图

## 🔄 创建顺序详解

```
时间线 ────────────────────────────────────────────────────────────►

1. 基础准备
   ┌─────────────────┐
   │ 获取堆参数      │ init_byte_size = 8GB
   │ - Xms/Xmx      │ max_byte_size = 8GB  
   │ - 对齐检查      │ heap_alignment = 4MB
   └─────────────────┘

2. 虚拟内存预留
   ┌─────────────────┐
   │ ReservedSpace   │ mmap(8GB, PROT_NONE)
   │ heap_rs         │ 只预留地址空间
   └─────────────────┘

3. 卡表系统创建
   ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
   │ G1CardTable     │───►│ G1BarrierSet    │───►│ G1HotCardCache  │
   │ *ct             │    │ *bs             │    │ *_hot_card_cache│
   │ 16MB卡表        │    │ 写屏障管理      │    │ 热卡优化        │
   └─────────────────┘    └─────────────────┘    └─────────────────┘

4. 内存映射器创建（6个）
   ┌─────────────────┐
   │ heap_storage    │ 主堆存储映射器
   └─────────────────┘
   ┌─────────────────┐
   │ bot_storage     │ BOT映射器 (16MB)
   └─────────────────┘
   ┌─────────────────┐
   │ cardtable_storage│ 卡表映射器 (16MB)
   └─────────────────┘
   ┌─────────────────┐
   │ card_counts_storage│ 热卡计数映射器 (16MB)
   └─────────────────┘
   ┌─────────────────┐
   │ prev_bitmap_storage│ 上轮位图映射器 (128MB)
   └─────────────────┘
   ┌─────────────────┐
   │ next_bitmap_storage│ 当前位图映射器 (128MB)
   └─────────────────┘

5. 核心管理器初始化
   ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
   │ HeapRegionManager│───►│ G1RemSet        │───►│ G1BlockOffsetTable│
   │ _hrm            │    │ *_g1_rem_set    │    │ *_bot           │
   │ Region总管理器   │    │ 记忆集管理      │    │ 对象定位        │
   └─────────────────┘    └─────────────────┘    └─────────────────┘

6. 并发标记器创建
   ┌─────────────────┐    ┌─────────────────┐
   │ G1ConcurrentMark│───►│ G1ConcurrentMarkThread│
   │ *_cm            │    │ *_cm_thread     │
   │ 并发标记管理    │    │ 标记执行线程    │
   └─────────────────┘    └─────────────────┘

7. 堆扩展和最终配置
   ┌─────────────────┐
   │ expand()        │ 提交物理内存
   │ 创建Region对象  │ 初始化到8GB
   └─────────────────┘
```

## 📊 内存使用统计

| 组件 | 大小 | 用途 |
|------|------|------|
| 主堆区域 | 8GB | 对象存储 |
| BOT | 16MB | 对象定位 |
| Card Table | 16MB | 跨代引用跟踪 |
| Card Counts | 16MB | 热卡优化 |
| Prev Bitmap | 128MB | 上轮标记结果 |
| Next Bitmap | 128MB | 当前标记结果 |
| **总计** | **8.3GB** | **所有G1数据结构** |
