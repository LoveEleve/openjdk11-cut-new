# 2.3 return_entry (返回入口点) 详解

> 源码位置: `src/hotspot/share/interpreter/templateInterpreterGenerator.cpp:86-105`
>
> 当被调用方法返回时，执行流跳转到 `return_entry` 来恢复调用者状态。

---

## 1. 概述

### 1.1 什么是 return_entry？

当一个方法执行完 `return` 指令后，需要：
1. 恢复调用者的栈帧
2. 根据返回值类型处理栈顶
3. 跳转回调用点的下一条字节码

`return_entry` 就是完成这些工作的入口点。

### 1.2 为什么有多组？

不同的 `invoke*` 指令长度不同：
| invoke 指令 | 指令长度 | 说明 |
|-------------|----------|------|
| invokevirtual | 3 bytes | 2字节索引 |
| invokestatic | 3 bytes | 2字节索引 |
| invokespecial | 3 bytes | 2字节索引 |
| invokeinterface | 5 bytes | 2字节索引 + 2字节参数 |
| invokedynamic | 5 bytes | 4字节索引 |

返回后需要跳过调用指令，所以需要根据指令长度选择不同的 return_entry。

## 3. 源码分析

### 3.1 生成代码

```cpp:86:105:src/hotspot/share/interpreter/templateInterpreterGenerator.cpp
  { CodeletMark cm(_masm, "return entry points");
    const int index_size = sizeof(u2);
    Interpreter::_return_entry[0] = EntryPoint();  // 空入口
    for (int i = 1; i < Interpreter::number_of_return_entries; i++) {
      address return_itos = generate_return_entry_for(itos, i, index_size);
      Interpreter::_return_entry[i] =
        EntryPoint(
                   return_itos,  // btos → 使用 itos
                   return_itos,  // ztos → 使用 itos
                   return_itos,  // ctos → 使用 itos
                   return_itos,  // stos → 使用 itos
                   generate_return_entry_for(atos, i, index_size),  // 对象引用
                   return_itos,  // itos
                   generate_return_entry_for(ltos, i, index_size),  // long
                   generate_return_entry_for(ftos, i, index_size),  // float
                   generate_return_entry_for(dtos, i, index_size),  // double
                   generate_return_entry_for(vtos, i, index_size)   // void
                   );
    }
  }
```

**优化**: byte/boolean/char/short 都使用 int 的入口 (`return_itos`)。

### 3.2 generate_return_entry_for (x86-64)

```cpp:175:238:src/hotspot/cpu/x86/templateInterpreterGenerator_x86.cpp
address TemplateInterpreterGenerator::generate_return_entry_for(
    TosState state, int step, size_t index_size) {
  address entry = __ pc();

  // 1. 恢复栈指针
  __ movptr(rsp, Address(rbp, frame::interpreter_frame_last_sp_offset * wordSize));
  __ movptr(Address(rbp, frame::interpreter_frame_last_sp_offset * wordSize), NULL_WORD);

  // 2. 恢复 bcp 和 locals
  __ restore_bcp();
  __ restore_locals();

  // 3. 如果是对象引用，进行类型 profiling
  if (state == atos) {
    __ profile_return_type(mdp, rax, tmp);
  }

  // 4. 从常量池缓存获取参数大小
  __ get_cache_and_index_at_bcp(cache, index, 1, index_size);
  __ movl(flags, Address(cache, index, Address::times_ptr, 
          ConstantPoolCache::base_offset() + ConstantPoolCacheEntry::flags_offset()));
  __ andl(flags, ConstantPoolCacheEntry::parameter_size_mask);

  // 5. 调整栈（弹出被调用方法的参数）
  __ lea(rsp, Address(rsp, flags, Interpreter::stackElementScale()));

  // 6. JVMTI 检查
  if (JvmtiExport::can_pop_frame()) {
    __ check_and_handle_popframe(java_thread);
  }
  if (JvmtiExport::can_force_early_return()) {
    __ check_and_handle_earlyret(java_thread);
  }

  // 7. 分发到下一个字节码
  __ dispatch_next(state, step);

  return entry;
}
```

## 5. 执行流程

```
被调用方法执行 return 指令
│
├── 1. 查找返回入口
│   ├── 根据调用指令类型确定 step（指令长度）
│   └── 根据返回值类型确定 TosState
│
├── 2. 跳转到 return_entry[step].entry(tos_state)
│
└── return_entry 执行:
    │
    ├── 3. 恢复调用者栈帧
    │   ├── movptr rsp, [rbp + last_sp_offset]
    │   └── restore_bcp, restore_locals
    │
    ├── 4. 获取参数大小
    │   └── 从 ConstantPoolCache 读取 parameter_size
    │
    ├── 5. 调整栈指针（弹出参数）
    │   └── lea rsp, [rsp + parameter_size * 8]
    │
    ├── 6. JVMTI 检查
    │   ├── check_and_handle_popframe
    │   └── check_and_handle_earlyret
    │
    └── 7. 分发到下一个字节码
        └── dispatch_next(state, step)
```

## 6. 示例

### 6.1 Java 代码

```java
public int caller() {
    int x = callee(10, 20);  // invokevirtual (3 bytes)
    return x + 1;
}

public int callee(int a, int b) {
    return a + b;
}
```

### 6.2 执行过程

```
caller 执行 invokevirtual callee
│
├── 进入 callee
│   └── 执行 ireturn（返回 30）
│
├── 跳转到 return_entry[3].entry(itos)
│   │   step=3 (invokevirtual 长度)
│   │   state=itos (返回 int)
│   │
│   ├── 恢复 caller 的 bcp, locals
│   ├── 弹出参数 (a, b) 共 2 个槽
│   └── dispatch_next(itos, 3)
│
└── caller 继续执行下一条字节码
    rax = 30 (返回值在栈顶)
```

## 8. 总结

| 项目 | 值 |
|------|-----|
| 代码大小 | 2880 bytes |
| 组数 | 6 组 (index 0-5) |
| 每组入口数 | 10 个 (按 TosState) |
| 优化 | btos/ztos/ctos/stos 共享 itos 入口 |
| 功能 | 方法返回后恢复调用者状态 |

### TosState 映射

| TosState | 索引 | 说明 |
|----------|------|------|
| btos | 0 | byte → 使用 itos |
| ztos | 1 | boolean → 使用 itos |
| ctos | 2 | char → 使用 itos |
| stos | 3 | short → 使用 itos |
| atos | 4 | 对象引用 |
| itos | 5 | int |
| ltos | 6 | long |
| ftos | 7 | float |
| dtos | 8 | double |
| vtos | 9 | void |
