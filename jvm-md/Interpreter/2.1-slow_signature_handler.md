# 2.1 slow_signature_handler 详解

> 源码位置: `src/hotspot/share/interpreter/templateInterpreterGenerator.cpp:58-60`
>
> 这是 `generate_all()` 生成的**第一个 Codelet**，用于处理复杂方法签名的参数传递。

---

## 1. 概述

### 1.1 什么是 slow_signature_handler？

当 JVM 调用 **本地方法 (native method)** 时，需要将 Java 参数转换为 C/C++ 的调用约定（x86-64 System V ABI）。

JVM 有两种签名处理器：
| 类型 | 说明 | 性能 |
|------|------|------|
| **快速签名处理器** | 为特定方法签名生成专用汇编代码 | 快 |
| **慢速签名处理器** | 调用 VM 运行时通用处理 | 慢 |

**使用 slow_signature_handler 的场景**：
- 首次调用 native 方法，还未生成快速处理器
- 参数类型过于复杂无法优化
- 内存不足无法生成快速处理器

### 1.2 在 generate_all() 中的位置

## 5. x86-64 汇编实现

### 5.1 源码位置

```cpp:116:176:src/hotspot/cpu/x86/templateInterpreterGenerator_x86_64.cpp
address TemplateInterpreterGenerator::generate_slow_signature_handler() {
  address entry = __ pc();

  // rbx: method
  // r14: pointer to locals
  // c_rarg3: first stack arg - wordSize
  __ mov(c_rarg3, rsp);
  // adjust rsp
  __ subptr(rsp, 14 * wordSize);  // 分配 112 字节栈空间
  __ call_VM(noreg,
             CAST_FROM_FN_PTR(address,
                              InterpreterRuntime::slow_signature_handler),
             rbx, r14, c_rarg3);

  // rax: result handler
  // 栈布局:
  // rsp: 5 integer args (if static first is unused)
  //      1 float/double identifiers
  //      8 double args
  //      return address
  //      stack args
  //      ...
  
  // 处理浮点参数...
  // 处理整型参数...
  
  __ addptr(rsp, 14 * wordSize);  // 恢复栈
  __ ret(0);
  return entry;
}
```

### 5.2 执行流程

```
调用 slow_signature_handler (entry = 0x7fffe1008c60)
│
├── 1. 保存上下文
│   ├── mov c_rarg3, rsp          ; 保存栈指针
│   └── subptr rsp, 112           ; 分配栈空间
│
├── 2. 调用 VM 运行时
│   └── call_VM(InterpreterRuntime::slow_signature_handler)
│       │
│       ├── 参数1: rbx = Method*
│       ├── 参数2: r14 = locals pointer
│       └── 参数3: c_rarg3 = 栈参数位置
│       │
│       └── 返回: rax = result_handler 地址
│
├── 3. 处理浮点参数 (System V ABI: xmm0-xmm7)
│   └── 根据 float/double 标志位加载到 XMM 寄存器
│
├── 4. 处理整型参数 (System V ABI: rdi, rsi, rdx, rcx, r8, r9)
│   ├── 检查是否静态方法
│   └── 加载参数到对应寄存器
│
├── 5. 恢复栈
│   └── addptr rsp, 112
│
└── 6. 返回
    └── ret
```

### 5.3 x86-64 System V ABI 调用约定

| 参数类型 | 寄存器 | 说明 |
|----------|--------|------|
| 整型 1 | rdi | 实例方法: this; 静态方法: JNIEnv* |
| 整型 2 | rsi | 实例方法: JNIEnv*; 静态方法: jclass |
| 整型 3 | rdx | 第1个 Java 参数 |
| 整型 4 | rcx | 第2个 Java 参数 |
| 整型 5 | r8 | 第3个 Java 参数 |
| 整型 6 | r9 | 第4个 Java 参数 |
| 浮点 1-8 | xmm0-xmm7 | float/double 参数 |
