# 2.5 safept_entry (安全点入口) 详解

> 源码位置: `src/hotspot/share/interpreter/templateInterpreterGenerator.cpp:154-168`
>
> 安全点入口用于在解释执行期间响应 VM 的安全点请求（如 GC、偏向锁撤销等）。

---

## 1. 概述

### 1.1 什么是安全点 (Safepoint)？

安全点是 JVM 中所有线程都暂停的同步点，用于执行全局操作：
- **垃圾回收 (GC)**
- **偏向锁撤销**
- **代码反优化 (Deoptimization)**
- **线程转储 (Thread Dump)**
- **类重定义 (Class Redefinition)**

### 1.2 解释器中的安全点检查

解释器在以下位置检查安全点：
- **后向跳转 (backward branch)** - 循环中
- **方法返回 (return)**
- **方法调用 (invoke)**

```

address TemplateInterpreterGenerator::generate_safept_entry_for(
        TosState state,
        address runtime_entry) {
  address entry = __ pc();
  __ push(state);              // 1. 保存栈顶值
  __ call_VM(noreg, runtime_entry);  // 2. 调用 at_safepoint
  __ dispatch_via(vtos, Interpreter::_normal_table.table_for(vtos));  // 3. 继续执行
  return entry;
}
```

## 3. 执行流程

```
解释执行字节码
│
├── 检查安全点标志
│   ├── 位置: 后向跳转、方法返回、方法调用
│   └── SafepointSynchronize::is_synchronizing() ?
│
├── 如果需要安全点 → 跳转到 safept_entry[tos_state]
│   │
│   ├── 1. push(state)
│   │   └── 保存当前栈顶值到栈
│   │
│   ├── 2. call_VM(InterpreterRuntime::at_safepoint)
│   │   └── 进入安全点，等待 VM 操作完成
│   │
│   └── 3. dispatch_via(vtos, _normal_table)
│       └── 安全点结束，继续执行下一个字节码
│
└── 如果不需要安全点 → 继续正常执行
```

IRT_ENTRY(void, InterpreterRuntime::at_safepoint(JavaThread* thread))
  // 如果有待处理的安全点操作，在这里等待
  if (SafepointSynchronize::is_synchronizing()) {
    SafepointSynchronize::block(thread);
  }
  
  // 处理其他异步事件
  if (thread->has_async_condition()) {
    // 处理异步异常等
  }
IRT_END

void TemplateInterpreterGenerator::set_safepoints_for_all_bytes() {
  for (int i = 0; i < DispatchTable::length; i++) {
    Bytecodes::Code code = (Bytecodes::Code)i;
    if (Bytecodes::is_defined(code))

## 8. 与 GC 的关系

当 G1 GC 需要执行时：

```
GC 线程请求安全点
│
├── SafepointSynchronize::begin()
│   └── 设置安全点标志
│
├── 等待所有 Java 线程到达安全点
│   │
│   ├── 解释器线程:
│   │   ├── 后向跳转时检查 → safept_entry
│   │   └── 调用 at_safepoint() 阻塞
│   │
│   ├── JIT 编译代码:
│   │   └── 轮询 polling page
│   │
│   └── native 代码:
│       └── 返回 Java 时检查
│
├── 所有线程到达安全点 → 执行 GC
│
└── SafepointSynchronize::end()
    └── 唤醒所有线程
```
