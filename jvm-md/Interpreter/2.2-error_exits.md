# 2.2 error_exits 详解

> 这是 `generate_all()` 生成的**第二个 Codelet**，包含错误退出入口点。

---

## 1. 概述

### 1.1 什么是 error_exits？

`error_exits` 包含两个错误处理入口点：
- `_unimplemented_bytecode` - 遇到未实现的字节码时跳转
- `_illegal_bytecode_sequence` - 遇到非法字节码序列时跳转

这些入口点用于捕获解释器中的致命错误，立即停止 VM 并输出错误信息。

### 1.2 在 generate_all() 中的位置

```cpp:62:65:src/hotspot/share/interpreter/templateInterpreterGenerator.cpp

    _unimplemented_bytecode    = generate_error_exit("unimplemented bytecode");
    _illegal_bytecode_sequence = generate_error_exit("illegal bytecode sequence - method not verified");
  }
```

## 4. 源码分析

### 4.1 generate_error_exit

```cpp:267:271:src/hotspot/share/interpreter/templateInterpreterGenerator.cpp
address TemplateInterpreterGenerator::generate_error_exit(const char* msg) {
  address entry = __ pc();
  __ stop(msg);
```

### 4.2 MacroAssembler::stop (x86)

`stop()` 宏生成的代码会：
1. 打印错误消息
2. 打印寄存器状态
3. 调用 `os::abort()` 终止 VM

```cpp:src/hotspot/cpu/x86/macroAssembler_x86.cpp
void MacroAssembler::stop(const char* msg) {
  pusha();                      // 保存所有寄存器
  call_VM_leaf(CAST_FROM_FN_PTR(address, report_vm_error), 
               r15_thread, msg);
  int3();                       // 调试断点
}
```

## 5. 使用场景

### 5.1 未实现字节码

当解释器分发表中某个字节码没有实现时，会跳转到 `_unimplemented_bytecode`：

```cpp:296:301:src/hotspot/share/interpreter/templateInterpreterGenerator.cpp
void TemplateInterpreterGenerator::set_unimplemented(int i) {
  address e = _unimplemented_bytecode;
  EntryPoint entry(e, e, e, e, e, e, e, e, e, e);
  Interpreter::_normal_table.set_entry(i, entry);
  Interpreter::_wentry_point[i] = _unimplemented_bytecode;
}
```

### 5.2 非法字节码序列

当字节码校验失败或方法未正确验证时，分发到 `_illegal_bytecode_sequence`：

```cpp:304:318:src/hotspot/share/interpreter/templateInterpreterGenerator.cpp
void TemplateInterpreterGenerator::set_entry_points(Bytecodes::Code code) {
  // 默认设置为 _illegal_bytecode_sequence
  address bep = _illegal_bytecode_sequence;
  address zep = _illegal_bytecode_sequence;
  // ...
  if (Bytecodes::is_defined(code)) {
    // 只有定义了的字节码才生成正确的入口
    Template* t = TemplateTable::template_for(code);
    set_short_entry_points(t, bep, cep, sep, aep, iep, lep, fep, dep, vep);
  }
}
```
