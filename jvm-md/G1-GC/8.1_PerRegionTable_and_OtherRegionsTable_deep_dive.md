# G1 RemSet 深入分析 - PerRegionTable & OtherRegionsTable

> 标准环境: `-Xms8g -Xmx8g -XX:+UseG1GC`, Region 大小 4MB, CardsPerRegion 8192

---

## 1. 设计哲学与核心问题

### 1.1 为什么需要三层 RSet 结构？

**核心问题**：如何高效存储跨 Region 引用？

```
问题分析：
- 每个 Region 最多有 2047 个其他 Region 可能引用它
- 每个 Region 有 8192 张 Card
- 如果全量存储：2047 × 8192 bits = 16MB/Region，内存爆炸！

解决方案：分层存储，根据引用密度自适应选择存储方式

密度        存储方式           内存占用
─────────────────────────────────────────────
极低 (0-12) Sparse Table     ~96 bytes
中等 (12+)  Fine-grain PRT   ~1KB (Bitmap)
很高 (溢出) Coarse Bitmap    1 bit/Region
```

### 1.2 三层结构整体架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                    HeapRegionRemSet (328 bytes)                      │
│  ┌─────────────────────────────────────────────────────────────────┐│
│  │              OtherRegionsTable (主要存储)                        ││
│  │  ┌─────────────────────────────────────────────────────────┐   ││
│  │  │  _sparse_table (SparsePRT)                              │   ││
│  │  │  ├── RSHashTable                                        │   ││
│  │  │  │   ├── SparsePRTEntry[] (Region→Cards 映射)           │   ││
│  │  │  │   └── _buckets[] (哈希桶)                            │   ││
│  │  │  └── 每个 Entry: RegionIdx + 最多12个 CardIdx           │   ││
│  │  └─────────────────────────────────────────────────────────┘   ││
│  │                                                                  ││
│  │  ┌─────────────────────────────────────────────────────────┐   ││
│  │  │  _fine_grain_regions[] (PerRegionTable* 哈希表)         │   ││
│  │  │  ├── PerRegionTable 0: Region 5 → Bitmap (8192 bits)   │   ││
│  │  │  ├── PerRegionTable 1: Region 12 → Bitmap             │   ││
│  │  │  └── ... (最多768个 PRT)                               │   ││
│  │  └─────────────────────────────────────────────────────────┘   ││
│  │                                                                  ││
│  │  ┌─────────────────────────────────────────────────────────┐   ││
│  │  │  _coarse_map (CHeapBitMap)                              │   ││
│  │  │  └── 1 bit per Region (2048 bits = 256 bytes)           │   ││
│  │  │      表示"这个 Region 有引用，但不确定是哪张 Card"      │   ││
│  │  └─────────────────────────────────────────────────────────┘   ││
│  └─────────────────────────────────────────────────────────────────┘│
└─────────────────────────────────────────────────────────────────────┘
```

## 2. PerRegionTable 深度分析

### 2.1 功能定位

**一句话说明**：PerRegionTable 是 Fine-grain 模式的 RSet 存储单元，为每个**引用方 Region**维护一张 Card Bitmap。

**在整体流程中的位置**：
```
写屏障发现跨 Region 引用
        │
        ▼
DirtyCardQueue (缓冲区)
        │
        ▼
Refine 线程处理
        │
        ├── 引用很少 → Sparse Table (SparsePRTEntry)
        │
        └── 引用较多 ────────────────┐
                                   │
                    ┌──────────────┴──────────────┐
                    │                             │
            需要精确记录 Card         溢出转换为 Coarse
                    │                             │
                    ▼                             ▼
            PerRegionTable (Fine)          Coarse Bitmap
            (8192-bit Bitmap)              (1 bit/Region)
```

### 2.2 类定义与继承关系

```
CHeapObj<mtGC> (GC 内存分配基类)
    └── PerRegionTable (Fine-grain RSet 存储单元)
```

**源码位置**：`src/hotspot/share/gc/g1/heapRegionRemSet.cpp:45-200`

### 2.3 关键字段详解

```cpp
class PerRegionTable: public CHeapObj<mtGC> {
  HeapRegion*     _hr;              // 指向引用方 Region
  CHeapBitMap     _bm;              // Card Bitmap (8192 bits)
  jint            _occupied;        // 已设置的 Card 数量
  PerRegionTable* _next;            // "all" 列表下一节点
  PerRegionTable* _prev;            // "all" 列表上一节点
  PerRegionTable* _collision_list_next;  // 哈希冲突链下一节点
  static PerRegionTable* volatile _free_list;  // 全局空闲列表
}
```

#### 字段详细分析

| 字段 | 类型 | 大小 | 说明 |
|-----|------|-----|------|
| `_hr` | HeapRegion* | 8 | 引用方 Region 指针 |
| `_bm` | CHeapBitMap | 24 | Card Bitmap 对象 |
| `_occupied` | jint | 4 | 有效 Card 计数 |
| `_next` | PerRegionTable* | 8 | "all" 链表前向指针 |
| `_prev` | PerRegionTable* | 8 | "all" 链表后向指针 |
| `_collision_list_next` | PerRegionTable* | 8 | 哈希冲突链指针 |

**_hr 字段**：
- **是什么**：指向引用方 Region 的指针
- **为什么需要**：知道这个 PRT 对应哪个 Region 的引用
- **怎么用**：通过 Region index 哈希定位 PRT
- **并发性**：使用 OrderAccess::release_store 保证可见性

**_bm 字段 (核心)**：
- **是什么**：CHeapBitMap 对象，存储 8192 张 Card 的标记
- **为什么需要**：精确记录引用方 Region 中哪些 Card 包含指向本 Region 的引用
- **怎么用**：`_bm.at(card_index)` 检查/设置 Card
- **内存占用**：8192 bits = 1024 bytes = 1KB

**_occupied 字段**：
- **是什么**：当前已标记的 Card 数量
- **为什么需要**：快速判断 PRT 占用率，用于决定是否转换为 Coarse
- **怎么用**：每次设置新 bit 时递增
- **并发性**：使用 Atomic::inc 原子递增

### 2.5 创建与分配

**源码位置**：`heapRegionRemSet.cpp:179-194`

```cpp
static PerRegionTable* alloc(HeapRegion* hr) {
    // 1. 尝试从空闲列表获取
    PerRegionTable* fl = _free_list;
    while (fl != NULL) {
        PerRegionTable* nxt = fl->next();
        PerRegionTable* res = Atomic::cmpxchg(nxt, &_free_list, fl);
        if (res == fl) {
            fl->init(hr, true);  // 复用并初始化
            return fl;
        }
        fl = _free_list;
    }
    // 2. 空闲列表为空，创建新的
    return new PerRegionTable(hr);
}
```

**内存分配流程**：
```
PerRegionTable::alloc()
        │
        ├── _free_list 不为空? ──► 从空闲列表弹出并初始化
        │
        └── _free_list 为空? ────► new PerRegionTable()
                                        │
                                        ├── 对象内存: sizeof(PerRegionTable) ≈ 56 bytes
                                        ├── Bitmap 内存: 1024 bytes (CHeap 分配)
                                        └── 总计: ~1080 bytes
```

### 2.6 Card 添加流程

```cpp
void add_card_work(CardIdx_t from_card, bool par) {
    if (!_bm.at(from_card)) {           // 1. 检查是否已设置
        if (par) {
            if (_bm.par_at_put(from_card, 1)) {  // 2. 原子设置
                Atomic::inc(&_occupied);          // 3. 原子递增计数
            }
        } else {
            _bm.at_put(from_card, 1);    // 非并行直接设置
            _occupied++;
        }
    }
}
```

## 3. OtherRegionsTable 深度分析

### 3.1 功能定位

**一句话说明**：OtherRegionsTable 是 Region RSet 的核心存储容器，管理三种粒度的引用记录（Sparse/Fine/Coarse）。

### 3.2 类定义

**源码位置**：`src/hotspot/share/gc/g1/heapRegionRemSet.hpp:74-168`

```cpp
class OtherRegionsTable {
    G1CollectedHeap* _g1h;
    Mutex*           _m;
    HeapRegion*      _hr;
    
    // Coarse 模式
    CHeapBitMap _coarse_map;
    size_t      _n_coarse_entries;
    static jint _n_coarsenings;
    
    // Fine 模式
    PerRegionTable** _fine_grain_regions;
    size_t           _n_fine_entries;
    PerRegionTable*  _first_all_fine_prts;
    PerRegionTable*  _last_all_fine_prts;
    size_t        _fine_eviction_start;
    static size_t _fine_eviction_stride;
    static size_t _fine_eviction_sample_size;
    static size_t _max_fine_entries;
    static size_t _mod_max_fine_entries_mask;
    
    // Sparse 模式
    SparsePRT   _sparse_table;
}
```

### 3.3 关键字段详解

#### Coarse 模式字段

| 字段 | 类型 | 大小 | 说明 |
|-----|------|-----|------|
| `_coarse_map` | CHeapBitMap | 24 | 粗粒度位图 |
| `_n_coarse_entries` | size_t | 8 | Coarse Region 数量 |
| `_n_coarsenings` | static jint | 4 | 转换到 Coarse 次数(全局) |

**_coarse_map**：
- **是什么**：每个 Region 对应 1 bit
- **大小**：2048 bits = 256 bytes (8GB/4MB = 2048 Regions)
- **语义**：bit[i]=1 表示 Region i 有引用，但不确定是哪张 Card

#### Fine 模式字段

| 字段 | 类型 | 大小 | 说明 |
|-----|------|-----|------|
| `_fine_grain_regions` | PerRegionTable** | 8 | PRT 指针数组 |
| `_n_fine_entries` | size_t | 8 | 当前 PRT 数量 |
| `_first_all_fine_prts` | PerRegionTable* | 8 | "all" 链表头 |
| `_last_all_fine_prts` | PerRegionTable* | 8 | "all" 链表尾 |
| `_max_fine_entries` | static size_t | 8 | 最大 PRT 数(768) |

**_fine_grain_regions (哈希表)**：
- **是什么**：PerRegionTable* 数组，哈希存储
- **大小**：768 个槽位（基于 G1RSetRegionEntries）
- **哈希函数**：RegionIndex % _max_fine_entries

**_first_all_fine_prts / _last_all_fine_prts**：
- **是什么**：双向链表维护所有活跃的 PRT
- **为什么需要**：快速遍历所有 PRT，无需扫描整个哈希表

#### Sparse 模式字段

| 字段 | 类型 | 大小 | 说明 |
|-----|------|-----|------|
| `_sparse_table` | SparsePRT | 16 | 稀疏表对象 |

### 3.5 引用添加流程

```
OtherRegionsTable::add_reference(from, tid)
        │
        ├── 1. 计算 from 所在的 Region (from_hr) 和 Card Index
        │
        ├── 2. 检查 Coarse Map
        │   └── 已设置? ──► 直接返回 (已在 Coarse 模式)
        │
        ├── 3. 检查 Sparse Table
        │   ├── 存在且未满? ──► 添加到 Sparse Entry
        │   └── 存在但已满? ──► 转换为 Fine 模式
        │
        ├── 4. 查找 Fine-grain PRT
        │   ├── 找到 PRT? ──► 添加 Card 到 PRT
        │   └── 未找到? ──► 创建新 PRT 并添加
        │
        └── 5. Fine Table 已满?
            └── 是 ──► 驱逐一个 PRT 到 Coarse Map
```

## 7. 关键流程时序图

### 7.1 引用添加时序

```
时间线    应用线程              Refine 线程              RSet 结构
─────────────────────────────────────────────────────────────────────────
T1        写屏障执行
          标记 Card 为 dirty
              │
T2              └──► 加入 DCQ
                        │
T3                      └──► 取出 Card
                              解析 from 地址
                              │
T4                            ├── 查 Sparse ──► 添加成功
                              │
T5                            ├── 查 Fine PRT ──► 设置 Bitmap bit
                              │
T6                            └── 表满 ──► 驱逐到 Coarse
                                              设置 Coarse bit
```

### 7.2 GC 扫描时序

```
时间线    GC 线程              RSet 迭代器           PRT/Sparse
────────────────────────────────────────────────────────────────
T1        开始扫描 RSet
              │
T2            └──► 创建迭代器
                    _is = Sparse
                      │
T3                    ├── 遍历 Sparse Table
                    │   产出 Card Index
                    │
T4                    └── _is = Fine
                        遍历 _first_all_fine_prts 链表
                          │
T5                        ├── 对每个 PRT
                        │   └── 遍历 Bitmap
                        │       产出 Card Index
                        │
T6                        └── _is = Coarse
                            遍历 _coarse_map
                            产出整个 Region 的 Cards
```

## 8. 总结

### 8.1 核心数据结构对比

| 结构 | 用途 | 内存占用 | 适用场景 |
|-----|------|---------|---------|
| **SparsePRTEntry** | Region→少量 Cards 映射 | ~96 bytes | 引用极少 (<12 Cards) |
| **PerRegionTable** | 精确 Bitmap 记录 | ~1KB | 引用中等 (12+ Cards) |
| **Coarse Bitmap** | 仅记录 Region 级别 | 1 bit/Region | 引用极多 (溢出) |
